Upgrade from 7.2.4 or 8.1

Read the Database Migration Guide and save a complete backup first. This package supports two methods: start CarillonBells.exe to upgrade the existing database in place, or start CarillonMigration.exe to create a separate v9 copy. Choose before starting either program. A later copy does not undo an earlier in-place upgrade. The guide explains checks and recovery for each method.

Set up your flash drive

Plug the flash drive into the computer youâ€™ll use to run the bells. Open File Explorer and look under This PC for the drive.

  1. Choose a package. Use New Install for an empty flash drive or Upgrade for a drive that already runs 7.2.4 or 8.1. Download the Installer ZIP for your Windows type. It contains Setup, a PDF guide and START_HERE.txt; no second download is needed.
  2. Put the files on the flash drive. Close the older program first if youâ€™re upgrading. Right-click the Installer ZIP and choose Extract All to unpack it into a folder on your computer. In that extracted folder, double-click the Setup EXE. Select your USB folder, click Install, then Verify. For New Install, use an empty USB. For Upgrade, select the existing folder beside databases. Do not run Setup from inside the ZIP.
  3. Start the program for your chosen method. For New Install or Method A, double-click CarillonBells.exe in the intended USB installation. For Method B, start CarillonMigration.exe instead and follow the guide to create a separate folder. Do not start CarillonBells.exe against the original database first if you intend to keep that database in its old format.

Windows may still warn about a newly downloaded program after extraction. ZIP packaging does not replace a publisher signature or download reputation. If a file is blocked, check its source and ask the supplier or administrator for help. See Microsoft’s explanation of SmartScreen warnings.
