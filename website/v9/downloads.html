Choose a software package

Pick New Install if you’re starting from scratch or Upgrade if you already run the bells. To check which package fits your computer, open Windows Settings, choose System, then About. Look for System type to see whether your PC uses 32-bit Windows or 64-bit Windows on an x64 processor.

New Install

Use an empty USB flash drive, a small storage device you plug into the computer. The package includes the program, a starter chime schedule, recordings, and instructions.

  • 32-bit Windows (win-x86)
  • 64-bit Windows (win-x64)
Read the Quick Start Guide

Upgrade from 7.2.4 or 8.1

Keep your schedule, settings, and music on the same drive. If you’re using 7.2.4, the app guides you through a backup and conversion of your saved schedule. If you’re using 8.1, the app opens your saved schedule directly.

  • 32-bit Windows (win-x86)
  • 64-bit Windows (win-x64)
Read the Database Migration Guide

Set up your flash drive

Plug the flash drive into the computer you’ll use to run the bells. Open File Explorer and look under This PC for the drive.

  1. Choose a package. Use New Install for an empty flash drive or Upgrade for a drive that already runs 7.2.4 or 8.1. If you use the optional Setup program, it saves the ZIP file to a folder on your computer.
  2. Put the files on the flash drive. Close the older program first if you’re upgrading. In File Explorer, right-click the ZIP file and choose Extract All. Select the drive itself as the destination so the program goes in the main folder you see when you open the drive.
  3. Start the bell program. Open CarillonBells.exe on the drive. If you’re coming from 7.2.4, follow the on-screen steps and check your schedule before turning scheduled playback back on. If you’re coming from 8.1, the program uses the schedule already on the drive.

Seasonal random music repeats each year. Enter month/day dates such as 10/1 through 10/31, without a year. Groups and song schedules retain full dates; point at a date field to reveal its calendar button. Groups asks to save only when values actually change.

System shows one Ash Wednesday date; the older compatibility value stays synchronized automatically. For larger text, open System → Font settings…, choose a font and size, and click Check every page. When the check passes, Apply checked font saves the choice and confirms it. Restore defaults returns to the original appearance.
