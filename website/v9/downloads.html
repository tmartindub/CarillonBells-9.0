Set up on USB

The planned portable packages follow the same steps for either Windows architecture.

  1. Choose the matching ZIP. Use New Install for an empty USB drive or Upgrade for an existing 7.2.4 or 8.1 installation. The optional Package Studio Pro setup saves the matching ZIP to a folder on your PC.
  2. Extract to the USB root. Close the older app first if you are updating an existing drive. In File Explorer, choose Extract All and select the USB root.
  3. Start from the USB. Open CarillonBells.exe on the USB. For 7.2.4, confirm the database conversion and review the schedule before re-enabling playback. For 8.1, the application uses the database already on the drive.

Check the Windows audio output and play a test chime before leaving the system unattended. Quick Start Guide (PDF)
