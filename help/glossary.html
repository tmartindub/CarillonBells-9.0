Glossary

Occurrence
One scheduled song record at a specific local date and time.
Playlist key
The pair of playlist name and song path identifying a record.
Weekly silence
A reusable time window associated with starting weekdays.
Legacy silence
The separate liturgical and one-off funeral silence settings.
Random directory slot
An annual directory choice; slot 1 is fallback and slots 2–7 are overrides.
Evaluation mode
A launch mode that suppresses automatic email while retaining actual scheduling and playback.
Portable base
The directory containing the executable.
STARTTLS
An explicit upgrade of an SMTP connection to TLS before authentication.
SQLite
The embedded database engine used by Carillon.
